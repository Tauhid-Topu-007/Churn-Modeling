# Customer Churn Prediction Dashboard

An AI-powered web application that predicts customer churn risk using deep learning, with interactive visualizations and batch processing capabilities.

## 📊 Overview

This application provides a complete solution for customer churn prediction, featuring:
- Real-time individual customer churn prediction
- Batch processing for multiple customer records
- Interactive visualizations and risk analysis
- Model performance insights
- Actionable retention recommendations

## 🚀 Features

### 1. **Individual Predictor**
- Interactive form for customer data input
- Real-time churn probability calculation
- Visual gauge chart for probability display
- Risk factor analysis
- Personalized retention strategies

### 2. **Batch Prediction**
- CSV file upload for bulk predictions
- Template download for easy data preparation
- Progress tracking for batch processing
- Results download capability
- Summary statistics for batch analysis

### 3. **Model Insights**
- Performance metrics display (Accuracy, Precision, Recall, F1-Score)
- Feature importance visualization
- Retention recommendations by risk level
- Model architecture overview

### 4. **User Experience**
- Dark/Light theme toggle
- Responsive design
- Interactive visualizations with Plotly
- Professional dashboard layout

## 🛠️ Technologies Used

- **Frontend & UI**: Streamlit
- **Deep Learning**: TensorFlow/Keras
- **Data Processing**: Pandas, NumPy, Scikit-learn
- **Visualizations**: Plotly, Plotly Express
- **Navigation**: streamlit-option-menu
- **Model Artifacts**: Pickle for encoders/scalers

## 📋 Prerequisites

- Python 3.8+
- pip package manager
